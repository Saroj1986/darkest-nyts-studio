# Darkest Nyts Studio V1.1 — UI/UX Upgrade

This build keeps the working V1.0.3 local video renderer and adds a premium Darkest Nyts studio interface: clearer hierarchy, creator-oriented dashboard, production wizard, visual preview, status states, responsive navigation, and cleaner queue/settings views.

## Run

```bash
npm install
npm run build
npm run dev
```

Keep your existing `.env.local` in this folder. FFmpeg must be installed locally for MP4 rendering.
